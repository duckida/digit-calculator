# my digit calculator

This is a calculator for the [Hack Club Digit](https://digit.smol.hackclub.com/) YSWS!

## Features
- Controlled by a XIAO ESP32-C3 
- BlackBerry-style trackball with RGB LED
- I2C OLED to display menus and calculations
- Support for LiPo battery and switch
